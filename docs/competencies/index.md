# Skills

Four competencies this portfolio documents, each mapped to the
[NACE Career Readiness Competencies](https://www.naceweb.org/career-readiness/competencies/career-readiness-defined)
and supported by linked evidence. Each page states the scope of the work, the
applied technique, the evidence, and what the work changed about how I operate.

## NACE mapping

| Competency | NACE areas |
| --- | --- |
| Web application penetration testing | Technology, Critical Thinking |
| Technical security writing | Communication, Professionalism |
| Assessment triage and severity judgment | Critical Thinking |
| Authorized and compliant testing practice | Professionalism, Technology |
