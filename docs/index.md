## What I do

I run authorized penetration tests against web applications and network
services, working primarily in Kali Linux with Burp Suite for application
testing and Metasploit for exploitation and post-exploitation. On the cloud
side I assess AWS environments with ScoutSuite and write the findings up in a
form an engineering team can act on.

The coursework behind that spans offensive security, network and wireless
security, cryptography, and the legal and regulatory frameworks that decide
what a test is allowed to touch. The projects below are the evidence.
