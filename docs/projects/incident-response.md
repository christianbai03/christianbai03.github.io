## Methodology note

Worth stating explicitly on this page which framework the response followed,
whether NIST SP 800-61 or another model, and where you deviated from it.
Interviewers ask about the framework, and a candidate who can name their model
and then explain where it did not fit reality is more convincing than one who
recites the phases.
